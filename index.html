🔐 Account Login / Cloud Sync

Mag-login gamit ang email mo para awtomatikong ma-sync ang data mo (applications, monitoring, bulletin, bank/credit contacts, calendar, notes) sa kahit anong device — laptop, phone, atbp. Ang totoong storage ay ang sarili mong libreng GitHub repo; ang GitHub token + repo ang gumagana bilang "password" ng account mo, kaya ito rin ang ibibigay mo sa ibang tao balang araw para maka-login din sila sa parehong account.

Gawa ka ng token sa github.com → Settings → Developer settings → Personal access tokens → Fine-grained token → bigyan ng Read & Write access sa "Contents" ng repo na gagamitin mo. Naka-save lang ito dito sa browser mo — hindi ito ipinapadala kahit saan maliban sa GitHub mismo.
